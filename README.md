# 🎯 Number Guessing Game (Python)

A beginner-friendly Python project where the computer selects a random number
and the user tries to guess it with hints provided.

- Random number generation
- User input handling
- Loop & condition logic
- Attempt counter

## 🧠 Concepts Used

- While loop
- If-else
- Random module
